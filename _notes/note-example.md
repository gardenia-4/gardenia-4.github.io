## 01 Web3.0
Web3.0 是以区块链为基础、结合分布式账本、智能合约和通证机制的去中心化互联网范式，强调用户对链上资产的控制，以及协议的开放性和可组合性。
| 术语 | 英文全称 | 考场答法 |
|---|---|---|
| **DApp** | Decentralized Application | 去中心化应用，核心业务逻辑可由区块链上的智能合约执行。 |
| **DeFi** | Decentralized Finance | 去中心化金融，用智能合约提供交易、借贷等金融服务。 |
| **NFT** | Non-Fungible Token | 非同质化代币，每个代币有独特标识，可用于表示门票、藏品等。 |
| **DAO** | Decentralized Autonomous Organization | 去中心化自治组织，由成员依据公开规则参与治理，常见流程是提案、讨论、投票、执行。 |
| **GameFi** | Game Finance | 将游戏与代币、NFT 等链上经济机制结合，玩家可通过游戏活动获得或使用链上资产。 |
